# Boardwalk Bikers

Mobile-first 3D bike racer (single HTML file, Three.js r128 from cdnjs).
One map (Pier Loop), 4 bikers: Redd, Blu, Green, Purp. You pick one, the
other three are AI. 3 laps, yellow boost pads, auto-gas, brake button.

- Phone: on-screen left/right + brake. Desktop: arrows or A/D, Space to brake.
- Look matches the Rolling Tides style: toon steps, black inverted-hull outlines, dusk sky.
- To run locally: open `index.html` in a browser (needs internet for three.js + fonts).
- Tweak constants at the top of the script (`LAPS`, `MAX_SPD`, `BOOST_SPD`, `TURN`).
